# 🏕️ Тропа — AI-консультант по документам

Умный AI-ассистент для интернет-магазина снаряжения для хайкинга, треккинга и кемпинга. Помогает клиентам быстро находить информацию в документации, каталоге товаров и базах знаний.

## 🚀 Основные возможности
*   **Поиск по базе знаний:** Ассистент отвечает на вопросы, опираясь на загруженные документы (доставка, возврат, гарантии, характеристики товаров).
*   **Строгий контроль галлюцинаций:** В настройках задан режим «Строго по базе знаний» (RAG-подход), что исключает выдумывание фактов.
*   **Быстрые ответы:** Предустановленные кнопки для частых вопросов (доставка, возврат, гарантия).
*   **Интерфейс:** Удобный чат с поиском по документам и быстрыми подсказками.

## 🛠 Стек технологий
*   **AI-модель:** Google Gemini API (Gemini 3.8 Flash).
*   **Платформа:** Google AI Studio.
*   **Интеграция:** Векторный поиск по документам (RAG).
